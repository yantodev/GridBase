# GridBase V1.3.2

Rilis PATCH ini memperbaiki isolasi build lokal yang dapat merusak respons kolom,
query, Activity, atau MCP saat aplikasi masih berjalan.

## Perbaikan

- Compiler menargetkan Java 17 secara eksplisit melalui `--release 17` pada
  launcher lokal, tes Java, dan build Docker. JDK yang lebih baru tidak lagi
  menghasilkan class yang tidak dapat dimuat runtime Java 17.
- `JAVA_HOME` dipakai untuk memilih compiler dan runtime yang sama, bukan
  mengandalkan `java`/`javac` lain pada PATH.
- `npm run check` membangun class di direktori sementara terpisah dan membersihkan
  hasilnya setelah selesai; tidak menimpa class layanan yang sedang berjalan.
- Setiap startup memakai direktori runtime baru di `build/java-runs/` sehingga
  build berikutnya tidak mengubah class yang belum dimuat oleh JVM lama.
- Tes regresi menjalankan compiler/JVM nyata, memeriksa versi bytecode, memastikan
  direktori deployment tidak ditimpa, dan memuat class kolom secara lazy setelah
  pemeriksaan build lain selesai.

## Upgrade lokal

Restart layanan untuk keluar dari JVM yang class-nya sudah tertimpa. Restart
mengakhiri sesi browser dan koneksi aktif; login ulang lalu Connect profil
tersimpan. Profil dan database aplikasi tidak dihapus.

Hasil build runtime lama hanya boleh dibersihkan saat semua instance yang
memakainya telah dihentikan. Jangan menghapus class milik proses aktif.
Tidak ada perubahan API, skema database, ataupun izin database.
