# GridBase V1.0.0

Rilis perdana GridBase: workbench SQL berbasis Java JDBC untuk **Spark Thrift / Hive,
PostgreSQL, dan MySQL**, dengan antarmuka browser bertema gelap bergaya database IDE.

## Fitur utama

- **Multi koneksi database:** tambah, simpan, uji, hubungkan, edit, dan putuskan koneksi.
  Setiap console memiliki koneksi sendiri sehingga query dan metadata tetap mengarah
  ke data source yang dipilih.
- **Database explorer:** telusuri schema, tabel, kolom, dan tipe data; buka tabel untuk
  membuat console SQL dan gunakan refresh serta filter objek yang sudah dimuat.
- **SQL consoles:** beberapa tab, rename, syntax highlighting, format SQL, saran keyword
  dan objek, serta eksekusi seleksi atau statement aktif melalui Ctrl/Cmd+Enter.
- **Query baca dan tulis:** jalankan SELECT, SHOW, DESCRIBE, EXPLAIN, DDL, serta DML sesuai
  dukungan dan izin database. Hasil baca tanpa LIMIT dibatasi 50 baris secara default;
  LIMIT eksplisit tetap diikuti.
- **Hasil query:** pagination, sorting, filter hasil, detail baris vertikal, ekspor CSV/JSON,
  serta output eksekusi dan jumlah baris terdampak jika tersedia dari driver.
- **Penyimpanan profil:** konfigurasi koneksi, termasuk password dan JDBC URL, tersimpan
  terenkripsi AES-GCM di SQLite pada server. Draft SQL dan riwayat query disimpan di browser.
- **Login GitHub wajib:** halaman workbench dan API database dilindungi sesi server,
  OAuth state, PKCE S256, cookie HttpOnly, masa sesi 8 jam, dan tombol Keluar.
  `GITHUB_ALLOWED_USERS` dapat membatasi akun yang boleh login.
- **Docker Compose:** image membawa Java, Spark 3.5.6, serta driver JDBC PostgreSQL,
  MySQL, dan SQLite. Volume data mempertahankan profil serta kunci enkripsi.
- **Dokumentasi dan versioning:** README dengan badge teknologi lengkap, kontrak OpenAPI,
  file VERSION, panduan VERSIONING, dan perintah npm untuk bump serta pemeriksaan versi.

## Memulai

1. Salin `.env.example` menjadi `.env`.
2. Buat GitHub OAuth App dan isi `APP_URL`, `GITHUB_CLIENT_ID`, serta `GITHUB_CLIENT_SECRET`.
   Untuk akses terbatas, isi `GITHUB_ALLOWED_USERS` dengan username GitHub yang diizinkan.
3. Jalankan aplikasi:

   ```bash
   docker compose up --build -d
   ```

4. Buka `http://127.0.0.1:4173`, masuk dengan GitHub, lalu tambahkan database melalui
   **Add connection**.

Callback OAuth lokal: `http://127.0.0.1:4173/auth/github/callback`. Untuk deployment
server, gunakan domain HTTPS dan sesuaikan `APP_URL` beserta callback pada OAuth App.

Panduan lengkap tersedia di [README](https://github.com/yantodev/GridBase/blob/V1.0.0/README.md)
dan [VERSIONING](https://github.com/yantodev/GridBase/blob/V1.0.0/VERSIONING.md).

## Catatan penggunaan

- Semua akun yang diizinkan memakai workspace dan profil koneksi yang sama, termasuk
  akses Edit ke kredensial tersimpan. Jika `GITHUB_ALLOWED_USERS` kosong, semua akun
  GitHub dapat login. Isi daftar tersebut untuk membatasi akses workspace.
- Setelah restart, pengguna perlu login ulang dan menghubungkan kembali profil database.
  Profil tersimpan dipulihkan dalam status disconnected.
- Backup profil memerlukan `data/gridbase.sqlite` dan `data/credentials.key` secara bersama.
- Pengeditan sel langsung dan pengelolaan transaksi melalui UI belum tersedia.
- Tes OAuth memakai penyedia identitas tiruan; koneksi JDBC diuji dengan fixture.
  Integrasi dengan akun GitHub dan database nyata memerlukan konfigurasi pengguna.

## Validasi release

Persiapan release menjalankan `npm test`, `npm run check`, dan `npm run version:check`
dengan `SPARK_HOME` yang sesuai instalasi lokal.
