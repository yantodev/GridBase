# GridBase V1.3.1

Rilis PATCH ini memperbaiki keterbacaan nilai JSON pada modal Row detail.

## Perbaikan

- Objek dan array JSON valid otomatis ditampilkan dengan indentasi dua spasi
  dan baris baru ketika detail baris dibuka, baik lewat nomor baris maupun klik ganda.
- Format hanya mengubah whitespace di luar string. Angka besar/desimal, urutan
  key, key duplikat, serta escape pada string tetap dipertahankan persis.
- JSON tidak valid, teks biasa, scalar, dan nilai SQL NULL tetap ditampilkan
  seperti sebelumnya. Hasil tabel dan data ekspor tidak diubah.
- Nilai tetap dirender sebagai teks, bukan HTML, termasuk string JSON yang
  berisi tag atau skrip.

## Kompatibilitas

Tidak ada perubahan API, skema database, dependency, atau konfigurasi.
Refresh browser agar memuat JavaScript terbaru.
